# Deliverables

- `spreadsheets/`：最终或汇总工作簿。
- `figures/`：用于论文、汇报和交付的成图。
- `presentations/`：正式演示文稿；当前框架已建立。

过程数据和批量计算输出不放在本目录。图表导出脚本默认读取
`spreadsheets/10_story.xlsx`，并写入 `figures/10_story_2015/`。

`MANIFEST.csv` 记录当前 10 个交付文件的相对路径、大小、修改时间和 SHA-256。
检查时未在活动项目目录中发现字节完全相同的来源文件，因此这些交付副本应按
独立成果保护，不能因为项目结果可重算就直接删除。
