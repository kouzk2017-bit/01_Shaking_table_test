# Common Code

此目录预留给 4 层、2015 年 10 层和 2018 年 10 层项目专用的共享函数。

`python/` 现包含 2015、2018 十层试验共同使用的 FFT 滤波、重采样、Raw CSV
读取、按物理量导出 CSV、CSV 绘图及 MATLAB 基准读取工具。年份相关的通道映射、
质量和人工修正规则仍由共享流程按项目显式区分，没有把同名但不同的算法混合。
计算入口与绘图入口已分离：前者只负责 Raw Data → CSV，后者只读已有 CSV。
2015 的贡献图按负向局部最低峰选点，2018 按正向局部最高峰选点，均不设置
最小峰间隔，并在选定后按时间顺序标记 A--D。

本项目所有活动 Python 绘图入口统一调用 `python/publication_style.py`。该模块集中管理
论文与演示两种画布、字体、字号、色板、线宽、坐标轴、刻度、网格、图例和导出规则；
默认论文模式输出 600 dpi PNG 和矢量 PDF。各图脚本只保留坐标范围、峰值、参考线等
与具体研究内容相关的设置，不再重复定义公共格式。

2015 与 2018 共用 `config/plot_config.json`。公共时间窗、楼层、图片模式等只定义
一次；两个年份不同的峰值方向作为同一配置文件中的年份规则保留。
