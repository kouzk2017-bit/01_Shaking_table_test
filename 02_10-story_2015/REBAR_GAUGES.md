# 2015 试验钢筋应变片位置与通道对应

2015 年资料里没有应变片配置图（`設置位置一覧` 没有应变片页，安装照片只拍了接线盒）。
本文整理目前能确定的应变片位置、依据和推断过程，以及由此对处理程序做的修改。
2026-10-01 整理。

## 1. 结论

### 1.1 编号规则（由 6F 节点论文图确认）

| 部位 | 编号 | 位置 |
|---|---|---|
| 梁端（每端 5 片） | 01、02 | 下筋 |
| | 03 | 腹筋 |
| | 04、05 | 上筋 |
| 柱（每根 20 片） | 01–10 | 柱脚 |
| | 11–20 | 柱头（两端布置相同） |

梁端编号的 E/W 表示梁的东端/西端。柱编号 `nF2AC` 表示 n 层 2-A 柱，也就是 A 轴 2 号中柱 C2。

### 1.2 方位

- G1 在 2 号中柱**东侧**。所以 2-A 中柱节点两侧的梁端是 **G1 西端（W）** 和 **G2 东端（E）**，
  **G1 东端连东侧角柱 C1**。
- 试验 Y 向（框架方向）层间位移角为正 = 上层**向西**移动。
- 论文节点图中 G1 画在左、G2 画在右，所以**图右 = 西**。
  DIANA 节点模型的"右侧"也对应试验的西侧（见 3.3）。

### 1.3 中柱节点（2-A）周围的应变片

| 节点 | 位置 | 应变片 |
|---|---|---|
| 6F | G2 东端下筋（图右下） | 6G21-STR-E01/E02 |

## 3. 依据

### 3.1 通道 ↔ 传感器编号

- 原始 CSV 第 2 行写有每个通道的传感器编号，例如 `235-4G1A-STR-E01`。
- 处理程序把 JB04（1–52 通道）、JB05（1–50）、JB06（1–62）、JB16（1–22）依次拼接后，按索引取通道，所以：
  - 索引 42 = JB04 第 43 通道
  - 索引 57 = JB05 第 6 通道
- 资料1（チャンネルリスト）和资料3（歪ゲージ抵抗値一覧表）给出编号与施工编号的对应，
  例如 4G1A-STR-E01 = はりA-4F-6，4F2AC-STR-02 = B-4F-2。

### 3.2 方位：G1 在中柱东侧

1. **平面图**：`documents/specimen_information/計測関係情報/03＿【資料2】---【設置位置一覧】.pdf` 第 19 页
   （梁端・柱頭柱脚の曲げ変形）。
   - C2 中柱四角的测点编号 4C2B-DZ-NE/NW/SE/SW 给出柱的方位。
   - G1WU-DY-1 在柱的东侧，G2EU-DY-1 在柱的西侧，G1EU-DY-1 指向东侧角柱。
2. **6F 编号**：论文图中 6F 中柱节点两侧的梁应变片编号是 6G11-**W** 和 6G21-**E**。

### 3.3 符号约定

- **试验**：同一资料第 10 页写明"Ｙ方向は、上層階が西に動いたらプラス"（上层向西为正），处理程序没有改号。
- **独立验证**：正向位移时，3F 柱头位移计 3C2T-DZ 西侧伸长约 +8 mm，4F 柱脚 4C2B-DZ 东侧伸长约 +10 mm，
  符合向西侧移时的受力。
- **DIANA**：试验历程加载沿用试验的正负号。正向位移时右梁下筋、下柱右侧筋受拉，说明 DIANA 的正向是顶部向右，
  所以 DIANA 右 = 试验西。

## 5. 节点位移计与应变片的楼层对应（2026-10-06）

設置位置一覧 p.16：位移计 JNT1–4 在 2F–5F 楼板，**6F 楼板没有**，JNT6 在 7F 楼板，均在 2-A 中柱。
`joint_rotation.csv` 和 Kang 图 13 按"层"命名（第 n 层顶部的节点叫 nF），所以其 "4F" = JNT4 = 5F 楼板节点，
"6F" = JNT6 = 7F 楼板节点。本文前面 1.3 节表格按**楼板**命名（4F 节点 = 4F 楼板 = 第 3 层顶部）。

| 节点（按层） | 楼板 | 位移计 | 应变片 |
|---|---|---|---|
| 3 | 4F | JNT3 | 3F2AC 柱头 11–20、4F2AC 柱脚 01–10、4G1A-W、4G2A-E |
| 4 | 5F | JNT4 | 4F2AC 柱头 11/12/18/19、5F2AC 柱脚 01/02/08/09、5G11-W、5G21-E |

## 6. 与 Kang et al. (EESD) 图 16（6F 楼板节点 = 节点 5）的核对（2026-10-08）

Kang 图 16(A) 的 8 个最大应变（μ）可以用本项目数据**精确复现**：每个位置取**两片的平均**、**从零开始**（不带前次残余），
误差 0%：右梁下筋 13,131 = E01+E02，上柱左筋 13,653 = 6F2AC-01+02，上柱右筋 1,483 = 08+09，
下柱左筋 3,649 = 5F2AC-11+12，下柱右筋 12,653 = 18+19。

左梁和右梁上筋的分组与本项目不同：
- 图中"左梁上筋 (1) 2,163" = **W01+W02**（2,160）；但 W01/W02 在负向位移时受拉（与层间位移角相关系数 −0.85/−0.79），是**下筋**。
- 图中"左梁下筋 3,762" = **W03+W04**（3,762）；6F 的 W03 表现为下侧（r = −0.94），W04 几乎不受力（r = +0.04）。
- 图中"右梁上筋 2,211" = E03+E04（本项目取 E04+E05）。
→ Kang 图 16 的左梁上/下标注有误；本项目 01/02 = 下筋、04/05 = 上筋 的分组由相关性检验支持（节点 3、4、5 的
G1 西端 01/02 都与位移角负相关，G2 东端 01/02 都正相关）。03 号片：节点 3、4 表现为上侧，节点 5 表现为下侧，位置不固定。
节点 5 左梁上筋无可靠数据（W05 损坏，W04 不受力）。
图 16(B) 的纵坐标似按 εy ≈ 1,600 μ 归一化（目测，(2) 尖峰 ≈ 8.5 对应 13,653 μ），本项目用 2,000 μ。
