# 破坏机理诊断：试验 vs 壳 vs 实体（2015 节点 4，试验历程协议）—— 收尾版（2026-10-06）

对象：**节点 4** = 第 4 层顶部（5F 楼板）中柱 2-A 节点，位移计 JNT4 与钢筋应变片在同一节点
（对应关系见 `02_10-story_2015/REBAR_GAUGES.md` 第 5 节）。节点变形角用 Kang 系数（`joint_rotation.csv`）。
模型：实体 `origin_2015_parabolic_gc61_residual20_history`，壳 `origin_history`，同一 1119 步试验历程协议。
判据：辻・長江（AIJ）柱梁接合部降伏破壊。这是机理诊断，不属于暂停中的"壳 vs 实体"结果对比。

## 3. 结论

**一致的部分（模型可用来解释机理）**
- 主筋屈服后节点变形占比逐循环上升（试验 0.37→0.79，壳 0.46→0.67，实体 0.38→0.71），层剪力无骤降；
- 受压对角线几乎不缩短、受拉对角线持续伸长：节点整体膨胀，三者一致；
- 模型中箍筋紧随主筋屈服、柱通长筋在节点内屈服、梁通长筋基本不屈服，斜压杆负担应力下降并绕行（云图），
  与辻论文的 ①–⑥ 机理一致（箍筋、通长筋试验未测）。

**不一致的部分（截取节点模型的局限）**
- 屈服顺序与程度：试验节点 4 是梁端（G1 西端下筋 7.3εy，残余约 6εy）为主、柱筋每个大峰值约 1.0–1.4εy（屈服但不增长），
  柱的明显塑性出现在相邻节点 3（柱脚 5εy）和节点 5（柱头尖峰 6–8εy）；两模型柱筋 5–11εy、柱先屈服。
- 已排除：混凝土强度（模型上柱反而偏强）、轴力（模型 243 kN vs 估算约 310–360 kN，影响约 5%）。
  二维 IMK 框架模型（Kobe 100% 在 13.07 s 第 4 层柱侧移倒塌，倒塌前反弯点在净高 0.45–0.52）也不支持"反弯点偏离层高中点"的解释。
  未查明的候选：无楼板、单节点边界无法让塑性在相邻楼层间转移、单元局部化与应变片位置。
- 受拉对角线模型偏大 1.2–1.5 倍；实体正向强度保持偏高（0.94–0.99，试验 0.81–0.92）；
  第一个转折点模型偏刚（试件此前已经历 7 次加载、已开裂）。
- 实体需 Gc 61 N/mm + 残余 20 MPa（高于 Mander 按节点箍筋的约 16 N/mm / 9 MPa，接近柱箍筋的约 39 N/mm / 23 MPa）才得到上述结果。

**钢筋对比的口径**：只比较"是否屈服、何时屈服"，不比较屈服后应变大小。
