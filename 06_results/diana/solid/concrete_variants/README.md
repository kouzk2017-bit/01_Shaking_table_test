# Solid model concrete variants vs. shell (origin)

同一实体网格、梁端铰支，每个版本只改一项混凝土设置：

- `origin_2015`：multi-linear 受压曲线（同壳模型保护层），泊松比按损伤折减（上一级目录 01–08 图用的就是这个）
- `origin_2015_nu_no_reduction`：泊松比不折减（第 106 步未收敛）
- `origin_2015_parabolic`：受压曲线改为 DIANA parabolic（按断裂能正则化），其余同 `origin_2015`；
  2026-09-28 中间检查，只导出了层剪力、角点位移、梁纵筋（约 260 步）。模型文件 `solid_BCJs - 2.dpf`
  （覆盖了泊松比不折减版本的 .out/.dnb，那一版的导出数据已保存）。

峰值前两个版本的 y 向箍筋应变相近（0.4–0.9εy，均未屈服），峰值后都屈服（约 7–10εy），所以泊松比
设置没有改变决定承载力时刻的约束作用。不折减版本峰值承载力反而降低约 12%，柱面梁纵筋更不屈服，
破坏模式仍是柱面附近梁上下区压坏；峰值后下降较缓、节点变形角较小，可能主要来自开裂混凝土保留的
泊松耦合，不宜当作约束效应。结论：泊松比按损伤折减（`origin_2015`）更合理。
