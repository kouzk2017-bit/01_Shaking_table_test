# Solid model concrete variants

同一实体网格、梁端铰支，每个版本只改一项混凝土设置。只比较实体自己的版本（不画壳、不画试验）。

- `origin_2015`：multi-linear 受压曲线，泊松比按损伤折减（基准）
- `origin_2015_nu_no_reduction`：泊松比不折减（第 106 步未收敛）
- `origin_2015_parabolic`：受压曲线改为 DIANA parabolic（按断裂能正则化），其余同 `origin_2015`；
  2026-09-28 中间检查，只导出了层剪力、角点位移、梁纵筋（约 260 步）。模型文件 `solid_BCJs - 2.dpf`
  （覆盖了泊松比不折减版本的 .out/.dnb，那一版的导出数据已保存）。
- `origin_2015_parabolic_fine`：parabolic，约 +0.0125 rad 起加密步长（步号之后跟其他版本不对应），
  只导出层剪力和角点位移，所以只出现在 01、02 图。

`03` 右柱面旁梁纵筋（10403/2954），`04` 节点箍筋 x 肢（10108/2665），`05` 节点箍筋 y 肢最大值

峰值前两个版本的 y 向箍筋应变相近（0.4–0.9εy，均未屈服），峰值后都屈服（约 7–10εy），所以泊松比
设置没有改变决定承载力时刻的约束作用。不折减版本峰值承载力反而降低约 12%，柱面梁纵筋更不屈服，
破坏模式仍是柱面附近梁上下区压坏；峰值后下降较缓、节点变形角较小，可能主要来自开裂混凝土保留的
泊松耦合，不宜当作约束效应。结论：泊松比按损伤折减（`origin_2015`）更合理。

## Parabolic 受压曲线（中间检查，约 260 步）

- 第 162 步（+0.016 rad）以前没有突降：+0.01 rad 386 kN、−0.01 rad −374 kN，
  +0.0125 rad 附近不再像基准版本那样骤降，+0.015 rad 仍有 374 kN。
- 第 163 步（+0.0165 rad）**未收敛**（200 次迭代，位移范数 0.032，容差 0.01），随后三步层剪力
  374 → 211 → 110 → 71 kN，+0.02 rad 只剩 52 kN，−0.02 rad 只有 −96 kN；节点变形角 0.006 → 0.017。
- 崩塌前柱面梁纵筋约 1.5εy，刚开始屈服。
- parabolic 软化段降到零、没有残余强度，压碎后该区完全失去承载力；而且崩塌恰好发生在未收敛步，
  第 163 步以后的路径不可靠，无法区分是物理破坏还是数值发散。
