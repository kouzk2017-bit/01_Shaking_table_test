# 节点模型进度汇报用图（PPT_20261006）

只收最终结果；中间过程只保留实体模型参数调整的两张汇总图和压碎截图。全部是从原结果复制来的，
重新生成原图后运行 `python 07_scripts/presentation/collect_joint_figures.py` 即可更新（或 `update_case.py ... --ppt`；文件夹位置由 `final_cases.json` 的 ppt_folder 决定）（DIANA 截图在 `_screenshots/`，脚本不会改动）。
图为 paper 样式（6.5×4.5 in，600 dpi）。对比对象统一为**试验节点 4**（第 4 层顶部，5F 楼板，JNT4）。
